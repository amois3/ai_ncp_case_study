# Trust and safety

Permission-aware AI needs a control that is stronger than a model instruction. The protected asset is not just document text: it includes room membership, the existence of private discussions, social relationships and the history of correction.

The reference core enforces the earliest useful boundary: a source that the actor cannot read cannot be retrieved, ranked or handed to an answer constructor. An output filter alone cannot provide this property because the private material has already affected the computation.

The private product adds authenticated services, database policy, event auditability, provider execution policy and operational controls. This repository is deliberately not represented as a complete production security system.
